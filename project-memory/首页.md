# seeda项目记忆

将仓库根目录作为 Obsidian Vault 打开，不要只打开 `project-memory/` 子目录。本页、文档图谱和项目本地 Skill 跟随当前 Git checkout；切换分支或提交后从当前版本重新接管。被引用的项目文件仍是权威来源。

## 接管工作

1. 确认当前 Git 分支或提交；刚发生切换时不沿用之前加载的上下文。
2. 阅读 [[project-memory/项目概览|项目概览]]。
3. 按任务读取 [[project-memory/项目背景与当前边界|项目背景与当前边界]]、[[project-memory/开发与运维注意事项|开发与运维注意事项]] 或 [[project-memory/环境与部署|环境与部署]]。
4. 选择下方相关工作流，先读其绑定的任务计划书，再读取最近一篇工作记录。
5. 如果最近记录不足以解释当前状态、决策、阻塞或依赖，按时间由近到远继续查阅当前 checkout 中的相关历史和引用来源，信息足够后停止。
6. 按 [[project-memory/协议|项目记忆协议]] 核对当前代码、配置和变更规范后再继续。
