# 项目概览

seeda 计划成为可自进化的本地 coding CLI；当前先建设最小终端交互与工具循环。完整架构见 [[docs/RSI架构设计]]，当前已实现核心与接入，运行与验证见 [[docs/Agent核心实现与验证]]。

## 当前架构

当前源码在 src/core、src/model、src/tools，简单终端驱动在 src/cli.ts。已完成本地及 DeepSeek 实测；TUI、版本与守护已实现，见 [[docs/版本守护与RSI运行指南]]。架构设计为：最小 Agent 循环、外部生命周期管理、Git 实现版本、SQLite 成长元数据、A/B 验证和请求边界接替。运行语言采用 TypeScript，前端采用 TUI；模型为 DeepSeek V4.1 Flash（deepseek-flash），原生 Chat Completions，不引入 SDK。

## 扩展和记忆

工具、模型与管理接口保持简单。会话历史由session管理；自身指令和通用记忆通过实现版本.agents/self显式保存加载，项目规则和项目知识保持cwd及可选Skill范围。见 [[docs/自身指令与项目规则]]。实现准备见 [[docs/RSI架构设计#14. 开始实现的步骤]]。

## 最小 TUI 进展

TUI 已通过独立变更实现，npm start 在交互终端默认启用；复用核心 run/cancel/事件，不写 session。类型、24 项回归、PTY 和真实 DeepSeek 样例通过。见 [[docs/TUI前端实现与验证]]。版本与守护及 A/B 接替已经实现并完成实测，使用见 [[docs/版本守护与RSI运行指南]]。

## 默认托管启动

npm start 默认自动初始化并后台启动守护，重开复用主实例和会话，Agent 默认拿到 management RSI 工具。退出前端不停止守护，manage stop 显式停服；start:direct 或 SEEDA_MANAGED=0 使用直接模式。默认项目 .seeda/runtime 隔离版本、成长和会话，SEEDA_HOME 保留显式覆盖。详见 [[docs/版本守护与RSI运行指南]]。

## TUI 展示

已支持消息分区、Markdown、代码/引用/表格、简洁工具条、Ctrl+O 详情、状态动画及中文显示。36 项回归和实际 PTY/默认 npm start 验证通过；见 [[docs/TUI前端实现与验证]]。

## 会话管理

默认托管前端支持 /new、/sessions、/resume 完整ID、/compact。当前选择独立于 Agent 版本保存在 SQLite，会话 JSONL 原始记录保留。手动摘要在核心执行；空闲时切换，旧版本缺少压缩能力明确提示升级。见 [[docs/版本守护与RSI运行指南]]。

## 种系与播种

全局种系库保存 Git 实现与 SQLite 目录，默认 ~/.local/share/seeda/strains-library，可用 SEEDA_LIBRARY 覆盖。origin 为通用初始种系；seeda strains 列举、seed 名称或ID 选择播种、publish 名称 [版本ID] 发布项目已保存提交。每个项目默认独立 .seeda/runtime，保存 seed_origin 和自己的版本父链、成长记录、会话及守护。Agent management 可查询和发布种系。已有项目不重新播种，不自动迁移旧运行库；嫁接 Graft 由 Agent 使用 Git/Bash 与现有候选接口完成，流程见 [[docs/Agent嫁接流程]]。详见 [[docs/RSI架构设计#16. 播种、种系与项目独立成长（2026-10-13）]] 与 [[docs/版本守护与RSI运行指南]]。

## Agent 自主嫁接

用户确认只保留基础接口：种系改进由 Agent 自己生成 Git 补丁、在目标 draft 应用/适配、提交并独立验证后接替。不新增嫁接工具、工件协议或数据库；源种系 ID/两端提交/范围写入 submit reason，过程沿用会话、Git、版本和验证记录。当前工具描述提供用法。

## 种系选择与标准介绍

全局默认可用 seeda strains default NAME 设置；首次交互 seeda/seed 显示搜索选择器，非交互采用默认，已有项目不变。新发布需要 introduction 的 summary/improvements/scenarios/limitations/validation 五项非空文本，CLI --intro FILE，Agent publish 携带对象。旧种系标明缺失，验证说明为发布者声明，不是平台认证。详见 [[docs/种系选择与发布]]。

## CLI 控制边界

入口任务必须显式 `seeda run "任务"` 或 `seeda -- "任务"`；无参数仍进入 TUI。所有管理命令及参数统一本地解析，未知命令不再作为任务。见 [[docs/CLI命令与参数]]。
