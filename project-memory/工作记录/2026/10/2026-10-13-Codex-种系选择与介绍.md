## 实现
全局 catalog.db 新 settings/introductions 表保存默认 ID 和五项标准介绍；origin 新记录带基础介绍，旧记录不伪造而标缺失。发布先验证介绍，CLI --intro FILE、Agent publish introduction 对象；来源/提交/时间继续由系统记录。验证文字是发布者说明，不是平台质量认证。
新 src/strains/select.ts 复用安全文本/列宽/增量绘制，默认预选、关键词筛选、上下选择、详情分页、Enter播种、Esc/Ctrl+C取消；成功或取消恢复 raw/alternate screen。首次无参数交互 seeda 先选择，带prompt或非TTY按默认；已播种项目保持原状态。TTY 输出简洁，重定向保留 JSON，文本剥离外部控制序列。没有改变用户默认或原有版本。

## 调试与边界
独立 PTY 脚本初次等待退出时没持续读取输出，导致终端缓冲阻塞，改为等待期间排空 PTY；失败输出保留早期 strain-picker 目录。取消改为正常130退出，避免错误堆栈或继续启动。最初完整测试出现已有 Bash 进程组清理 EPERM，未削弱该安全措施；最终两次默认完整回归均48项通过，早期日志 /tmp/seeda-selection-tests.log 保留。
旧后台需重开加载新发布规范，旧保存 Agent 工具描述不会自动更新；可以用新版 CLI 发布或候选升级。旧种系可继续播种，介绍缺失明确显示。
