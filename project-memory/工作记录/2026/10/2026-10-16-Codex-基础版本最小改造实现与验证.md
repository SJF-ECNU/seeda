## 验证
- Node 24.18.0 全套默认并行回归：138/138，失败 0，跳过 0，43.468 秒。TypeScript 无输出通过，OpenSpec strict 通过。
- 本地 HTTP/SSE 模型夹具，无供应商模型调用；实际运行本地命令、Docker 命令、原生 Seatbelt 候选沙箱。验证同一 Agent 版本切换环境、非零退出、长输出、超时、取消、Supervisor SIGKILL 清理、候选不能使用宿主通道、旧版本能力缺失时明确拒绝 Docker 接入。
- 模拟管理流程 7→4 次调用，响应 23758→5756 字节；最终并行测量 3836.59→3868.42 毫秒，没有观察到耗时下降。不证明模型成本下降或自主进化收益。

## 决策
- 保留安全措施，不增加独立发布机制、免验证记忆通道或插件框架。
- 命令监护解决实际发现的 Supervisor SIGKILL 后清理责任丢失；不是新增长期服务。
- Docker 命令标识清理用于生命周期管理，不宣称抵御主动删除标识的恶意进程；候选安全仍由原沙箱负责。
