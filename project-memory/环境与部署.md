## 托管环境

Node 24.14+；默认运行根为项目 .seeda/runtime，Unix socket 位于该根；SEEDA_HOME 可显式连接旧运行库。npm start 自动导入首次实现、启动守护并接管理进程，项目 cwd 必须相同；手动 init/serve 仍可用于管理。验证使用 .seeda 内临时目录，没有为用户启用持久后台服务或改动系统启动配置。

## 默认托管启动

npm start 默认自动初始化并后台启动守护，重开复用主实例和会话，Agent 默认拿到 management RSI 工具。退出前端不停止守护，manage stop 显式停服；start:direct 或 SEEDA_MANAGED=0 使用直接模式。默认项目 .seeda/runtime 隔离版本、成长和会话，SEEDA_HOME 保留显式覆盖。详见 [[docs/版本守护与RSI运行指南]]。

## 项目播种默认布局（2026-10-13）

全局种系库与项目运行库分离。SEEDA_LIBRARY 默认 ~/.local/share/seeda/strains-library；项目 .seeda/runtime 保存独立 Git、SQLite、会话和守护。通用入口 npm link 后为 seeda，也可 node 直接运行源码；本轮不安装用户全局命令或迁移用户已有数据。旧根显式 SEEDA_HOME=$HOME/.local/share/seeda 继续连接，停旧守护也带同一覆盖变量。运行库子目录或 Git 子目录自动定位项目根，非 Git 首次使用 cwd。
