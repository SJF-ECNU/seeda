# 开发与运维注意事项

## 开始修改前

遵循 [[AGENTS]] 和 [[project-memory/协议]]；确认 Git 状态，绑定唯一任务计划。代码开发使用 OpenSpec；存在 .codegraph/ 时先用 CodeGraph 调查。

## 修改与验证

最小实现，局部修改，不推测未登记事实。文档变化检查链接；应用开发后根据实际工具链执行检查。当前使用 npm run check 和 npm test；直接与托管启动按运行指南执行。

## 安全与证据边界

凭据和完整环境文件不得进入记忆。文档检查不证明应用功能或生产健康；发布和不可逆操作需对应授权及实际验证。

## 权威入口

[[AGENTS]] · [[docs/文档规范]]

## RSI 实现边界

完整依据为 [[docs/RSI架构设计]]。质量由 Agent 评价，守护进程只处理生命周期；实现切换在请求边界完成。代码回退不撤销用户文件或外部副作用；worktree 不等于安全沙箱。

## 最小实现要求

增量 I 只实现可用 CLI、模型与工具接口、Bash、session 和通用 Skill；CLI 直接驱动核心。管理接口、SQLite 与守护在增量 II、III 加入。seeda 的开发协作遵循本仓库 Project Memory，但产品运行时不强制内置它。

## 首轮实现与验证入口

代码计划与清单使用 [[openspec/changes/implement-agent-core/design]] 和 [[openspec/changes/implement-agent-core/tasks]]。验证 npm run check、npm test；真实模型样例 npm run smoke:live 使用临时项目。不要把 .seeda 会话或凭据加入 Git。工作目录无 .codegraph/ 时不自动索引。

## 托管运行与回退

[[docs/版本守护与RSI运行指南]] 为当前运行依据。主 Agent 通过 management 工具修改候选、验证与请求接替；不要原地编辑启动版本。守护不判断质量，切换等待请求结束；实现回退不撤销业务文件。无自动重放请求，unknown 工具结果必须核实现场。直接模式不具备成长与守护；默认 npm start 自动初始化和启动，同一 cwd 连接前端。

## 默认托管启动

npm start 默认自动初始化并后台启动守护，重开复用主实例和会话，Agent 默认拿到 management RSI 工具。退出前端不停止守护，manage stop 显式停服；start:direct 或 SEEDA_MANAGED=0 使用直接模式。默认项目 .seeda/runtime 隔离版本、成长和会话，SEEDA_HOME 保留显式覆盖。详见 [[docs/版本守护与RSI运行指南]]。

## evaluate 沙箱

所有 evaluate 必须走宿主隔离入口，模型选 process/container，省略默认 process，不允许 none 或无隔离回退。macOS process 单进程，Bash 任务选 container；沙箱宿主实现不进入进化快照，不向候选透传长期模型凭据。当前实现和平台限制以 [[docs/evaluate沙箱]] 为准。
