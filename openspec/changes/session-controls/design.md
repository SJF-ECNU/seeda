# 会话控制
目标：四个用户命令可在默认托管模式运行，独立会话可重开恢复，版本切换沿用当前会话。
不增加知识记忆系统。main.jsonl 保持兼容；新会话使用 UUID 文件名，SQLite runtime_state 保存当前会话 ID。只有空闲主进程可切换，先关闭旧写入者，新进程 ready 后提交选择，失败恢复旧会话。会话历史广播给连接前端，保留输入草稿；旧前端提交携带已知会话 ID，防止陈旧页面写错会话。
主动压缩保留最近一轮完整对话，摘要更早历史（包括已有摘要），工具调用和结果不拆分。空会话或只有一轮时明确无需压缩。取消和失败不替换上下文，原始 JSONL 消息继续留存。旧版本 worker 用 ready 能力字段识别，缺少 compact 时明确提示升级，不发送会挂起的消息。
执行及验证见 tasks.md。现有后台不会因源码更新自动替换已保存的 Agent 版本；文档说明更新方法，保留回退能力。
