# reliable 自身运行记录

workstream: reliable-runtime-records

## 目标与范围
从现有会话记录恢复Agent可见的自身运行事实。新增runtime_records只读工具，当前会话最近任务（默认5，最多20）：实现版本、结束原因、模型请求数量/实际usage/耗时、工具状态/退出码/耗时。暴露实现目录和可用工具名，不提供诊断。旧记录缺少计量时明确未知。

## 实现
沿用session JSONL，扩展request/end时间字段及runtime观察条目，兼容原记录和压缩，保留原安全措施。Agent核心统一加入只读工具，记录正常/失败/取消的模型和工具调用；额外计量写入失败不能改变已有执行结果，查询明确计量不完整。只保存白名单字段，不复制输入输出、参数、reasoning或任意错误文本。模型请求按Agent接口计量，provider内部重试不虚构为单独请求。
工具输出有界，默认展示最近5个任务和每任务最近20个调用；不读取其他会话或实例。下次请求在system追加上一请求的结束状态/安全原因及查询入口，避免外层失败只在人类日志可见。

在主源码局部实现，并把对应Agent核心改动应用到从compact85指定提交克隆的独立候选，不混入竞技场配置。以本地新种系seeda-agent-reliable-runtime-records发布，不推送GitHub、不切换默认或现有实例。

## 验证
先回归复现length失败后不可见，再验证任务结束/模型usage/工具非零退出、超时、取消、旧记录、压缩重载、无副作用、无敏感文本及计量失败。完整类型与回归；compact85候选回归；真实DeepSeek读取先前失败事实并能指出缺失证据。保存本地种系和源码包并实际新项目播种查询。

用户后续明确授权提交并推送当前功能，以及将本地默认改为新种系。仅提交运行记录代码、测试、规范和相关文档；既有竞技场部署改动保留在工作区，不混入本次。已有实例不自动升级，竞技场仍暂停。
