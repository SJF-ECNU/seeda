# 随版本的自身指令、通用记忆与项目规则分离

workstream: versioned-agent-instructions

## 目标与范围
修复“自身AGENTS.md已接替但主cwd未加载”的架构缺口。自身指令、通用记忆随实现版本加载；项目规则随cwd加载。覆盖核心请求/压缩、直接与托管主运行、隔离候选、版本快照和运行记录。产品修复完成前不启动新的正式实验，不改变已结束实验记录。

## 假设与取舍
- `.agents/self/INSTRUCTIONS.md`和`.agents/self/MEMORY.md`随实现模块所在版本根目录加载，不复用根AGENTS.md；已有.agents快照路径足以保存，无需新Hash、冻结或Gate。
- 项目`cwd/AGENTS.md`及`cwd/.agents/skills/*/SKILL.md`保持现有行为；不复制自身文件到项目，不将项目记忆自动变成通用记忆。
- 缺少新文件的旧种系可运行，只显示未加载；不把仓库开发规则隐式迁移成自身规则。
- 单请求固定已读内容，后续请求/接替/回退重新读取实际版本。运行记录仅来源、存在/长度，不存正文，不据此声称行为收益。
- 保留候选隔离和质量由Agent决定的既有职责，候选不继承主项目规则，使用独立workspace。

3. 最小实现分层加载与来源记录，不修改产品外部控制边界（完成）。
4. typecheck、针对性与完整测试，补文档/实验准备适配（完成）。
