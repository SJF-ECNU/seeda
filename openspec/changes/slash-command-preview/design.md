# Slash 命令预览
范围只包括已有命令，不新增执行接口或自动调用。静态命令列表为 /new、/sessions、/resume、/compact、/versions、/use、/rollback、/exit。直接模式只提供 /exit。
输入以 / 开始且没有空格、光标在末尾、当前空闲时显示前缀匹配列表；编辑前缀重新从首项选择。上下键循环选择；Tab 补全文本；Enter 执行无参数命令，参数命令只填入命令及空格，不发送缺少参数的请求；Esc 收起，继续编辑再出现。无匹配时保持原有输入发送行为，不改变模型接口。
预览占用历史区底部最多六行，并随屏幕高度缩短，输入/状态/页脚保持固定位置。长列表随选中项移动可见窗口。只使用现有固定颜色、列宽裁剪与增量重绘。唯一执行清单见 tasks.md。
