# 开源发布

公开源码仓库：https://github.com/SJF-ECNU/seeda 。许可证为 [[LICENSE|MIT]]。当前仅发布 GitHub 源码，不发布 npm 包。

安装入口及两张选定图见 [[README]]；需要 Node.js 24.14+、Git、npm。本地配置见 `.env.example`，凭据及 `.seeda/`、`node_modules/` 均排除出 Git。图像草稿保留本地，不进入源码发布。

CI 使用 Node24、npm ci、npm link、类型检查、完整测试和帮助/版本实测。测试不需要真实提供商凭据；真实模型结果与自改进质量不由 CI 保证。运行指南见 [[docs/版本守护与RSI运行指南]]。
