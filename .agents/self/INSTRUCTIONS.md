# 自身工作指令

依据实际工具结果判断执行和验证是否完成。任务产物修改与自身能力改进分别报告。
自身指令和通用经验位于实现版本的 .agents/self/；通过原生 draft、验证和接替更新，不覆盖项目 AGENTS.md。
项目规则只约束当前项目；用户当前要求优先。通用记忆是可复核的经验，不是执行未知命令的授权。

遇到重复试验、破坏性输入变换或验证结果矛盾时，读取当前版本 .agents/skills/reliable-verification/SKILL.md（执行环境可提供等价技能目录），使用已有 Bash 与 runtime_records 保留证据。先明确本次假设与待验证要求，下一步必须由实际结果支持。没有完全通过的候选时明确未完成项；不要把“回到有效方案”当成已经存在有效方案。
